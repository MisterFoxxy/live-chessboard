# Обучение нейросети BoardNet

Нейросеть `js/board-net.js` учится на записях партий idChess. Ролик idChess имеет размер 720×1200: сверху (720×480) снята доска, снизу (720×720) idChess рисует свою цифровую доску. Цифровая доска служит разметкой: по ней известно, что стоит на каждой клетке в каждый момент.

Нужны Python 3 с numpy, scipy, opencv-python-headless, Pillow, torch, python-chess, а также ffmpeg и Node.js.

1. **Видео.** Положите ролики как `v01.mp4 … vNN.mp4`. Через приложение их можно отправить кнопкой «Видео для обучения ИИ», они попадут в папку `training/` репозитория отчётов.
2. **Позиции с цифровой доски.**
   ```
   python3 gt.py tpl.png vNN.mp4 gt/vNN.json 5
   ```
   `tpl.png` — любой кадр ролика idChess с начальной позицией, из него вырезаются шаблоны фигур.
3. **Грубые углы доски.** Нужны для каждого видео, точность ±15 пикселей кадра 720×480.
   * `python3 med.py vNN.mp4 med/vNN.png` строит кадр без рук (медиана по времени).
   * `gridsheet.py` рисует на нём сетку координат.
   * Углы игрового поля записываются строкой в `rough.txt`.
4. **Снимки для обучения.**
   ```
   ./run_extract.sh        # или python3 extract.py vNN
   ```
   `extract.py`:
   * уточняет углы по пересечениям клеток (`fitlib.py`);
   * сдвигом на клетку и ориентацией сверяет сетку с цифровой доской (`shiftcheck.py`);
   * отслеживает доску по ходу ролика;
   * сохраняет выпрямленные снимки (20 пикселей на клетку) с разметкой в `data/vNN.npz`.

   Клетки, где в кадре двигалась рука, получают класс «рука».
5. **Обучение и экспорт.**
   ```
   EPOCHS=14 VAL=v40,v41,v42,v43,v44 OUT=m1.pt python3 train.py
   python3 export.py m1.pt ../../models/board-net.bnet
   python3 evalnet.py m1.pt v40 v41 v42 v43 v44 --img=errors.png
   ```

Свои партии можно добавить как проверку или для дообучения: `user_extract.py` (по метаданным теста: углы, ходы и их время) и `finetune.py`.

Проверка записанной партии по её видео: `python3 verify_report.py папка_отчёта model.pt` (с `HIST="e4 e5 ..."` — проверить другой вариант записи). Для каждого момента находит позицию партии, лучше всего совпадающую с тем, что видит сеть, и показывает несовпадающие клетки.

Метаданные для покадровой проверки целых партий в приложении: `make_meta.py`, `make_meta3.py` и `calm.py`.

Проверка трекера на сохранённых ответах сети (без браузера):
```
python3 cache_net.py u8 отчёт/ m1_ft.pt 4          # ответы сети 4 раза в секунду
python3 cache_net.py u8_p1 отчёт/ m1_ft.pt 4 0.0625 # то же со сдвигом кадров на 1/16 с (_p2, _p3 — 1/8 и 3/16)
python3 export_cache.py u8; python3 export_cache.py u8_p1
TEST=папка_с_uNs.json node tracker_eval.js '{"conf":0.7}'          # совпадение с эталоном по партиям и сдвигам
GRID='{"pen":[3,4],"conf":[0.6,0.7]}' node grid_eval.js            # подбор настроек по всем партиям и сдвигам
node lat_eval.js                                                   # задержка от хода до записи
```

## Сеть типов фигур (в работе)

Сеть `board-net` различает только «пусто / белая / чёрная / рука». Тип фигуры пробовали узнавать двумя способами:

* 14 классов той же сетью (`train13.py`, 16 точек на клетку);
* отдельная сеть по крупному снимку каждой фигуры — вырез 2×2 клетки, 64×64 точки (`crops.py`, `cropnet.py`).

Проверка на партиях, которых сеть не видела (`eval13.py`, `TEST=` в `cropnet.py`): 82–88 % фигур. Ошибки не случайные: сеть
запоминает, что обычно стоит на этом месте (ладья на h7 — «конь», король на d2 — «ферзь»), потому что в партиях короли,
ферзи и ладьи почти всегда стоят на привычных клетках. Нужны съёмки, где каждая фигура побывала в разных местах доски.

`freemove.py` размечает такое видео само: фигуры переставляют по одной на любые клетки (правила не важны), а кто где стоит,
отслеживается по занятости клеток. Проверка на обычных партиях: 4435 клеток из 4441 совпали с разметкой по правилам.

```
python3 cache_net.py free1 отчёт/ m1_ft.pt 4          # ответы сети «цвет»
python3 freemove.py free1                              # разметка типов -> data13/free1_auto.npz
python3 crops.py free1 free1.json                      # крупные снимки фигур -> crops/free1.npz
ARCH=lite BAL=1 TRAIN="u1 u2 ... free1" TEST="u10 u11" OUT=crop.pt python3 cropnet.py
```

`boardview.py` — кадры доски, выпрямленные и повёрнутые белыми вниз (чтобы глазами проверить, что было на доске).

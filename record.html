Как начать запись
  1. Поставьте телефон так, чтобы вся доска попадала в кадр и была как можно крупнее: в держатель над центром доски или на штатив сбоку от доски и повыше. Не ставьте его за спиной игрока: рука после хода закроет фигуру от камеры.
  2. Расставьте фигуры в начальную позицию — программа сама найдёт доску и поставит сетку. Если сетка легла неточно, перетащите жёлтые точки на углы игрового поля (без рамки с буквами).
  3. Дождитесь зелёной сетки — значит, доска распознана.
  4. Запись начнётся сама с первым ходом. Ход засчитывается, как только вы отпустили фигуру и рука открыла клетку, — убирать руку с доски не нужно.
Настройки распознавания Нейросеть обучается прямо во время партии на вашей доске.
Ход белых ходов пока нет

Ход распознан неверно? Отмените его и сделайте правильный ход на цифровой доске: нажмите на фигуру, затем на клетку.

Отправьте видео партии и журнал программы — по ним можно увидеть, где распознавание ошиблось, и исправить его. Отправка на GitHub не зависит от размера видео.

Настроить отправку на GitHub

Видео и журнал загружаются в ваш закрытый репозиторий на GitHub — оттуда их забирает разработчик. Настраивается один раз.

  1. Создайте на github.com закрытый (Private) репозиторий, например live-chessboard-reports.
  2. Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Repository access: только этот репозиторий. Permissions → Contents: Read and write.
  3. Вставьте токен ниже (адрес репозитория уже вписан). Токен хранится только на этом телефоне и не сбрасывается при обновлении приложения.

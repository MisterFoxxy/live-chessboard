# Сервер пульта турнира

Пульт (`control.html` на ноутбуке) и телефоны на досках (`record.html`) общаются через этот маленький сервер:
телефоны сообщают, нашли ли доску, и присылают ходы; пульт видит все доски и даёт команду «Начать».
Сервер ничего не хранит на диске: комнаты турниров живут в памяти и удаляются через сутки без дела.

Нужен только Node.js 18+ (сторонних библиотек нет):

```
node server.js            # порт 8080; другой — PORT=9000 node server.js
curl http://127.0.0.1:8080/health
```

**Сервер должен быть доступен по https://** — страницы приложения открыты по https (GitHub Pages), и браузер
не даст им обращаться к http-адресу. Варианты:

1. **Ноутбук с пультом — программа на одну кнопку, без регистрации и карты (проще всего).** Нужен Node.js
   (nodejs.org, кнопка LTS). Скачать архив `download/pult-windows.zip` (ссылка есть на странице пульта), распаковать
   и дважды щёлкнуть `Pult.bat`; дальше — значок «Пульт турнира» на рабочем столе. Программа (`pult-app.js`) сама
   обновляет `server.js`, при первом запуске скачивает `cloudflared.exe`, запускает сервер и бесплатный туннель
   Cloudflare (`--protocol http2`: работает и в сетях, где закрыт QUIC), проверяет адрес `https://…trycloudflare.com`,
   открывает пульт с уже вписанным адресом (`control.html#server=…`; сохранённый турнир открывается сам) и не даёт
   ноутбуку уснуть, пока окно открыто. Туннель оборвался — перезапускается сам (адрес будет новый).
   Адрес новый при каждом запуске — телефонам нужны новые QR-коды с пульта.
   Вручную: `node server.js` и во втором окне `cloudflared tunnel --protocol http2 --url http://127.0.0.1:8080`.
   Такой туннель не пропускает потоки Server-Sent Events, поэтому телефоны забирают команды в ответ на отправку
   состояния (раз в 2 с), а пульт опрашивает сервер раз в 2 с.
2. **Render.com** (бесплатный тариф, но просит банковскую карту). New → Web Service → этот репозиторий; Root Directory: `server`; Build Command: пусто;
   Start Command: `node server.js`. Адрес будет вида `https://имя.onrender.com` — его и вписать на пульте.
   Бесплатный сервер засыпает после 15 минут без запросов и просыпается около минуты — откройте пульт заранее.
3. **Свой VPS.** `node server.js` под systemd или в Docker (`docker build -t pult server && docker run -p 8080:8080 pult`),
   а https даёт Caddy: в `Caddyfile` строка `pult.ваш-домен.рф { reverse_proxy localhost:8080 }`.
4. **Любой хостинг с Node.js** — то же самое: запустить `server.js`, адрес с https вписать на пульте.

Нагрузка маленькая: каждый телефон присылает состояние раз в секунду (около 300 байт), 30 досок — 30 запросов
в секунду, это по силам самому слабому серверу.

Как это работает (`server.js`):

| Запрос | Кто | Что |
|---|---|---|
| `POST /room {room, key, name}` | пульт | создать комнату турнира (ключ организатора придумывает пульт и хранит у себя) |
| `GET /room/stream?room&key` | пульт | поток состояний всех досок (Server-Sent Events) |
| `POST /room/cmd {room, key, cmd, boards, data}` | пульт | команда доскам: `start` (с именами игроков), `show`, `reset` |
| `GET /board/stream?room&board` | телефон | поток команд; команда `start` приходит и тому, кто подключился позже |
| `POST /board/status {room, board, seq, boot, …}` | телефон | состояние: ищет доску / готова / идёт запись, ходы, позиция, заряд; в ответе — команды новее `seq` и действующая «Начать» (`start`), `boot` меняется при перезапуске сервера |

Команды доскам принимаются только с ключом организатора; телефону достаточно кода комнаты и номера доски.
